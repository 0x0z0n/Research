How Mining Works

Currently the ONLY way to earn coins!

At this early stage, coins can only be earned through mining. Mining tasks are generated directly from pending network transactions, allowing miners to secure the blockchain and earn valuable coins. Accumulate enough to unlock VIP status and explore advanced features.

Since the BlockSynergy network is still in its infancy, transaction data is primarily created through our internal testing and simulation systems. These simulated transactions provide the essential workload for miners, ensuring that every validated block strengthens the network and contributes to its future readiness for real-world use. By participating now, you're not just mining coins—you’re laying the foundation of a growing decentralized economy.

All necessary mining data, including pending transactions and block information, is available directly via our public API endpoint at /mining_data. Get your mining client ready and start contributing to the network today!

📦 Submitting Blocks

To contribute mined blocks to the BlockSynergy network, simply submit them to the /submit_block endpoint using the following JSON structure: 

        payload = {
            'address': your_address,
            'block': your_block
        }

⚠️ Rewards are issued as transactions. You must mine a new block containing the reward transaction to actually receive your coins.
